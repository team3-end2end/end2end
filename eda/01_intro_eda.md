# EDA → Feature Engineering 단계 정리

```
Raw Data → EDA → EDA Findings → Feature Engineering → Modeling
                  (기록까지 EDA)   (여기서부터 수정)
```

> EDA는 진단서, FE는 치료. **찾는 것**과 **고치는 것**을 나눈다.
> EDA 중 원본은 수정하지 않는다. 확인이 필요하면 사본에서 본다. (`tmp = df[df['x'] > 0]`)
> 단계는 순서일 뿐 일회성이 아니다 — FE로 바꾼 뒤 다시 EDA로 확인한다.

## EDA — 4단계 (보고 기록만)

| 단계 | 할 일 |
|---|---|
| ① 구조 | 행·열 개수, 변수 타입 확인 |
| ② 품질 | 결측치, 중복, 모순값 확인 |
| ③ 변수 특성 | 컬럼 하나씩 분포·이상치·중심값 확인 |
| ④ 변수 간 관계 | 컬럼끼리 상관관계·패턴 확인 |

넓게 → 좁게. ②를 건너뛰고 ④를 하면 결과가 조용히 틀린다.

## Feature Engineering — 발견별 액션

| 발견 | 할 일 |
|---|---|
| 결측치 | 삭제 또는 대체 |
| 이상치 | 제거 또는 보정 |
| 컬럼 간 스케일 차이 | 스케일링 |
| 문자열 범주값 | 인코딩 |
| 치우친 분포 | 로그 변환 |
| 타겟 불균형 | 샘플링 |
| 원본 컬럼 조합 가능 | 파생변수 생성 |

## Modeling

학습 → 평가 → 예측/분류
