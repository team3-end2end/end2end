**결측이 동일 행에서 동시 발생 (검증: True)** → 랜덤 결측이 아니다. 원인은 아래 1-3에서 규명.

### head() vs sample()

```
head()   → 전부 2026-05-01 00시대 (시간순 정렬이라 5월 1일 새벽만)
sample() → 05-02, 05-09, 05-01, 05-23, 05-22 (고르게 분포)
pickup 범위: 2008-12-31 23:05 ~ 2026-06-01 00:20   ← 2008년 데이터 혼입
```
